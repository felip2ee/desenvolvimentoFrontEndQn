# desenvolvimentoFrontEndQn

Repositório referente aos estudos da matéria de Desenvolvimento Frontend cursada na ULBRA.

**Aplicação publicada (GitHub Pages):** [https://felip2ee.github.io/desenvolvimentoFrontEndQn/](https://felip2ee.github.io/desenvolvimentoFrontEndQn/)

Gerenciador de tarefas acadêmicas: HTML semântico (E1), layout responsivo com Grid e Flexbox (E2), dados carregados de `dados.json` com `fetch` e quatro estados de tela (E3), e estado único com busca, filtros, ordenação por prazo e limpeza (E4).

Para rodar localmente, sirva a pasta por HTTP (por exemplo, `npx serve` ou a extensão Live Server), não por `file:`.
